Bezier Transit Simulator

A browser-native demonstration inspired by the EightBitTransit shadow-imaging formalism: fill a 192 x 192 fractional-opacity grid with an irregular Bezier structure, slide that occulter along an arbitrary impact-parameter chord across a quadratic limb-darkened stellar disk, and integrate the resulting light curve at finite cadence — then export a light curve ready for the Python lightkurve package. No server required.

Load in Python (lightkurve) 
import os, lightkurve as lk

csv = os.path.expanduser("bezier_lightcurve.csv")
lc = lk.LightCurve.read(csv, format="csv",
                        time_column="time",
                        time_format="jd",
                        time_scale="tdb", comment="#")

# Promote the file's # header into lc.meta (lc.mission, lc.quarter, lc.seed, ...):
meta = {ln.split(":", 1)[0].lstrip("# ").strip().upper(): ln.split(":", 1)[1].strip()
        for ln in open(csv) if ln.startswith("#") and ":" in ln}
lc.meta.update(meta)

lc.scatter()
